Cada círculo é uma conta e cada seta é uma conexão dirigida (uma ou mais transferências no mesmo sentido). O tamanho do nó é proporcional ao degree. Passe o mouse para ver as métricas, clique para abrir o painel lateral e arraste para reorganizar.

Os padrões são encontrados por regras simples no backend Python. Encontrar um padrão indica que a conta merece verificação, não que houve irregularidade.
